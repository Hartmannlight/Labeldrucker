## Qualification still required

The earlier USB/Chrome development run proves useful behavior but used locally
built containers. The following scenarios must be repeated against the digest-
pinned candidate before a machine-readable acceptance record can say `pass`:

- public catalog and serialized maintenance baseline;
- queue isolation and FIFO recovery;
- response-loss idempotency, Agent restart and in-flight disconnect ambiguity;
- media-state invalidation;
- label browser PDF, color/dither comparison and deliberate A4 `hold` then
  `fit` release;
- review of the sanitized record by a different human from the tester.
