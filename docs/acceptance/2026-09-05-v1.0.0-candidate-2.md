# v1.0.0 hardware-qualification candidate 2

Status: superseded before physical qualification

This record fixes the artifacts used for the second stable hardware-
qualification candidate. It is not yet a hardware-acceptance record and does
not authorize a Compatibility Release. Any source or image change creates a
different candidate and requires the applicable checks to be repeated.

Candidate 1 was superseded when a fresh production database could not start.
The first non-printing setup of its successor then found a PostgreSQL row-access
defect in the Fleet worker healthcheck. Both defects were fixed before this
candidate was resolved. No physical job from either superseded revision counts
as release evidence.

Production startup then exposed two more defects before a physical job was
submitted: the non-root Fleet Console could not write its generated Nginx
configuration into a root-owned tmpfs, and the IPP server could not initialize
with its required local DNS-SD service disabled. Candidate 2 is therefore also
superseded; its digests remain here only as an audit trail.
